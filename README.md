# sql-learning-lab

**Query Field | SQL学習ラボ** は、ECサイトの商品・顧客・注文データを使って、ブラウザ上でSQLの基礎を学べる日本語の学習アプリです。テーブルの内容を確認しながらSQLを実行し、結果を見て学習を進められます。

SQLの実行には同梱のsql.js（SQLite）を使用します。データベースサーバーの構築や、外部APIの設定は不要です。

## 起動方法

リポジトリをダウンロードまたはクローンし、`index.html` をブラウザで開いてください。ビルドやパッケージのインストールは不要です。

ローカルHTTPサーバーを使う場合は、Python 3が利用できる環境で、リポジトリのルートから次のコマンドを実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000` を開きます。サーバーは `Ctrl+C` で終了できます。

## 学習できること

| レッスン | 内容 |
| --- | --- |
| 0. チュートリアル | テーブル・レコード・カラム・クエリの意味と操作方法 |
| 1. 最初のSELECT | 商品データをすべて取得 |
| 2. 列を選ぶ | 必要な列だけを取得 |
| 3. 条件で絞り込む | `WHERE` による条件指定 |
| 4. 並べ替える | `ORDER BY` による降順の並べ替え |
| 5. 集計する | `SUM` と `GROUP BY` による注文金額の集計 |
| 6. テーブルを結合 | `JOIN` による注文と顧客の結合 |
| 7. 商品を追加する | `INSERT` と追加したデータの確認 |
| 8. 主キー | IDの重複による制約エラーと、新しいIDでの登録 |
| 9. インデックス | 索引の作成前後で `EXPLAIN QUERY PLAN` を比較 |
| 発展編：ベクトル検索 | 2つの特徴量を使い、好みに近い商品をランキング |
| 自由SQLエディタ | 採点なしで検索・集計・データ編集・テーブル作成などを練習 |

ベクトル検索は手作業で設定した特徴量を使う入門例です。埋め込みモデルや外部のAIサービスは使用しません。発展編と自由SQLエディタは修了数に含まれません。

## 使い方

1. レッスン0で用語を確認し、「レッスン1へ進む」を押します。
2. 課題とテーブルプレビューを見ながら、SQLエディタにSQLを入力します。
3. 「SQLを実行」、または `Ctrl+Enter`（Macでは `Cmd+Enter`）で実行します。
4. 実行結果を確認し、正解したら次のレッスンへ進みます。困ったときは「ヒント」を開けます。

チュートリアル・主キー・インデックスのレッスンは、画面上の操作で修了します。レッスン一覧から好きな課題に移動することもできます。

「SQLを戻す」は入力内容をそのレッスンの初期SQLに戻します。データの変更を取り消す操作ではありません。

### 自由SQLエディタ

`SELECT` や `WITH` を使った分析に加え、`INSERT`・`UPDATE`・`DELETE`、テーブルやビューの作成・変更・削除などを試せます。複数のSQLはセミコロンで区切ります。

- 最初に開いた時点のINSERT演習データがコピーされ、以降の変更は演習側に影響しません。
- 途中でエラーが発生した場合、その回に実行したSQLによる変更はすべて取り消されます。
- 1つの結果が1,000行を超えるとエラーになります。必要に応じて `LIMIT` を指定してください。

## 練習データ

起動時に次の4テーブルが作成されます。

| テーブル | 内容 | 初期件数 |
| --- | --- | --- |
| `products` | 商品ID・商品名・分類・価格・在庫数 | 6 |
| `customers` | 顧客ID・氏名・居住地 | 3 |
| `orders` | 注文ID・顧客ID・注文日 | 4 |
| `order_items` | 注文ID・商品ID・個数・購入時の単価 | 6 |

`orders.customer_id` は `customers.id` に、`order_items.order_id` は `orders.id` に、`order_items.product_id` は `products.id` に対応します。テーブル定義と初期データは [course.js](course.js) にあります。

### 保存と初期化

- **修了記録**：ブラウザの `localStorage` に保存されます。同じブラウザ・同じオリジンでの再読み込み後も残りますが、ブラウザのサイトデータを削除すると失われます。別のブラウザや端末とは同期されません。
- **SQLの下書きと変更したデータ**：メモリ上に保持され、ページの再読み込みで初期状態に戻ります。
- **練習データの初期化**：INSERT演習と自由SQLエディタの「練習データを初期化」で、その画面のデータを初期状態に戻せます。修了記録は残ります。
